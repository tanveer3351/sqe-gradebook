# sqe-gradebook
SQE Gradebook is a simple Python project for managing student information and scores. It is being developed as part of Software Quality Engineering (SQE) lab work to practice Git, GitHub, branching, pull requests, code review, testing, and continuous integration.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/tanveer3351/sqe-gradebook.git
```

2. Enter the project directory:

```bash
cd sqe-gradebook
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Running Tests

Tests will be added in a later lab.

```bash
pytest
```
