# SQE GradeBook

SQE GradeBook is a Java-based student grade management project developed for Software Quality Engineering labs. The project stores student information and scores and will gradually include features for calculating and managing student grades.

## Installation

1. Clone the repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Make sure Java is installed.
4. Compile and run the Java files.
