↓

↓

↓

## QA Involvement

- Issue: QA helps clarify requirements.
- Branch: QA considers the tests required for the change.
- Pull Request: QA reviews the implementation and tests.
- Review: QA identifies defects and missing test cases.
- Merge: QA confirms review requirements are satisfied.
- CI: QA checks automated test results.
- Release: QA verifies that the software is ready for release.
